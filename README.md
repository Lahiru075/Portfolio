# 🚀 My Professional Portfolio

Welcome to my personal portfolio repository! This website showcases my skills, projects, and experience as a developer. Built with **React.js**, this project focuses on a clean UI, responsiveness, and performance.

---

## 🌐 Live Demo
Check out the live version here: [[Vercel Link](https://lahiru-sanjeewa.vercel.app/)]

---

## ✨ Features
- **Responsive Design:** Optimized for all screen sizes (Mobile, Tablet, Desktop).
- **Project Showcase:** A dedicated section displaying my best work with descriptions and links.
- **Skill Highlights:** Visual representation of my technical stack.
- **Contact Form:** Easy way for recruiters or clients to get in touch.
- **Smooth Animations:** Integrated using Framer Motion/CSS for a better user experience.

---

## 🛠️ Technologies Used
- **Frontend:** React.js
- **Styling:** Tailwind CSS 
- **Icons:** Lucide React
- **Version Control:** Git & GitHub
- **Deployment:** Vercel

## ⚙️ Installation & Setup

If you want to run this project locally, follow these steps:

### 1. Clone the repository:
  ```bash
  git clone https://github.com/Lahiru075/Portfolio.git
  ```

### 2. Navigate to the directory:
  ```bash
  cd Portfolio
  ```

### 3. Install dependencies:
  ```bash
  npm install
  ```

### 4. Start the development server:
  ```bash
  npm run dev
  ```

Open `http://localhost:3000` in your browser.
